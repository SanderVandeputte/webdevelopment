Lijsten

1.1 Normaal genummerde Lijst (<ol> </ol>):

HTML Code:


<ol>
    <li>Eerste item</li>
    <li>Tweede item</li>
    <li>Derde item</li>
</ol>

Output:

  1. Eerste item
  2. Tweede item
  3. Derde item

1.2 Genest genummerde Lijst (<ol> </ol>):

HTML Code:


<ol>
    <li>Dit is optie 1</li>
    <li>Dit is een optie met extra opties eronder:
        <ol>
            <li>Nummer 1</li>
            <li>Nummer 2</li>
        </ol>
    </li>
    <li>En hier is optie 3.</li>
</ol>

Output:

    1. Nummer 1
    2. Nummer 2
  3. En hier is optie 3.

Formulieren

Het <form>-element in HTML wordt gebruikt om invoer van gebruikers te verzamelen. Binnen een formulier kun je verschillende velden plaatsen, zoals tekstvakken, keuzerondjes, selectielijsten, checkboxes en knoppen. Wanneer de gebruiker het formulier verzendt, worden de ingevulde gegevens doorgestuurd naar een server of verwerkt door een script. Zo vormt <form> de basis voor interactie tussen een website en zijn bezoekers.

HTML Code:


<form action="verwerk.php" method="post">
  Naam: <input type="text" name="naam" required><br><br>
  E-mail: <input type="email" name="email"><br><br>
  Geslacht:
    <input type="radio" name="geslacht" value="man"> Man
    <input type="radio" name="geslacht" value="vrouw"> Vrouw<br><br>
  Interesses:
    <input type="checkbox" name="sport"> Sport
    <input type="checkbox" name="muziek"> Muziek<br><br>
  <input type="submit" value="Verstuur">
</form>

Output:

Naam:

E-mail:

Geslacht: Man Vrouw

Interesses: Sport Muziek

attributen voor <input> element

1. Autofocus (<input type="text">)

Autofocus is een attribuut dat ervoor zorgt dat het invoerveld automatisch wordt geselecteerd wanneer de pagina wordt geladen.
Dit is dan ook de reden waarom je hier altijd komt wanneer de pagina opent of herladen wordt.

HTML Code:


<form>
    Naam: <input type="text" name="naam" autofocus>
</form>

Output:

Naam:

<form>

canvas

Het <canvas>-element in HTML5 is een rechthoekig vlak waarop je met JavaScript kunt tekenen. Je kunt er vormen, lijnen, tekst, afbeeldingen en zelfs animaties of complete games mee maken. In tegenstelling tot gewone HTML‑elementen heeft <canvas> zelf geen inhoud; alles wat zichtbaar wordt, moet via JavaScript getekend worden. Het wordt vandaag nog steeds veel gebruikt, vooral in interactieve webapplicaties, visualisaties en grafische toepassingen zoals dashboards, grafieken en online spelletjes.

leeg canvas

HTML Code:


<canvas id="myCanvas" width="200" height="100" style="border:1px solid #000000;">
Your browser does not support the HTML5 canvas tag.
</canvas>

Output:

Your browser does not support the HTML5 canvas tag.

2. Canvas met tekening

HTML Code:


<canvas id="canvasDemo" width="300" height="150" style="border:1px solid #000000;">
Your browser does not support the HTML5 canvas tag.
</canvas>

<script>
    // Haal het canvas-element op
    var c = document.getElementById("canvasDemo");
    var ctx = c.getContext("2d");

    // Rode rechthoek
    ctx.fillStyle = "red";
    ctx.fillRect(20, 20, 100, 50);

    // Blauwe cirkel
    ctx.beginPath();
    ctx.arc(200, 75, 40, 0, 2 * Math.PI);
    ctx.fillStyle = "blue";
    ctx.fill();
</script>

Output:

Your browser does not support the HTML5 canvas tag.
